# LiDAR + IMU 실측 지도 · 잠정 진동 지표

## 반영한 화면

- `Map`: 실측 LiDAR 상대좌표에 IMU 진동 지표를 표시합니다.
- `Map_Demo`: 기존 카카오 도보 경로·시연 노면 등급·세 종류 길찾기를 유지합니다.
- `World Model`: 기존 기술 설명 화면을 유지합니다.

GPS 보정, 지도 방위 보정, 카카오 도로 스냅은 수행하지 않았습니다. 원본 JSON의 LiDAR 상대좌표를 사용하며 세션 1을 별도로 병진 이동하지 않았습니다. 세션 간 위치 정합의 불확실성도 그대로 남아 있습니다.

## 입력과 대응 범위

사용자가 확인한 `walkway_player/vibration_map`의 2026-10-16 측정 3개 세션을 사용했습니다. 원본 입력은 `trajectory.json`, `vibration.json`, `registration.json`이며, 각 파일의 SHA-256을 결과 데이터의 provenance에 기록했습니다.

| 항목 | 수량 |
| --- | ---: |
| LiDAR 프레임 | 25,387 |
| IMU 진동값 대응 프레임 | 24,818 |
| IMU 미대응 프레임 | 569 |
| 진동 지표 산정 표시 구간 | 487 |
| 미산정 표시 구간 | 2 |

미산정 2개 구간은 세션 1 시작의 541프레임과 세션 3 끝의 28프레임입니다. 미산정 값은 `null`로 저장하고 회색 점선으로 표시합니다. 0점으로 대체하지 않습니다.

## 잠정 산식 제안

원본 분석에 포함된 휴대폰 선형가속도 2–8 Hz 대역, 중심 1초 RMS 값을 사용합니다. 원본의 시간 대응은 `phone time = LiDAR time + offset`이며, 세션별 오프셋은 −1.77초, −1.77초, +0.24초입니다. 이번 구현에서 원시 가속도 필터링이나 시간 오프셋 추정을 다시 수행하지는 않았습니다.

시간순으로 최대 약 5m 또는 5초 단위로 묶고, 구간 내 프레임별 RMS의 중앙값을 계산했습니다. 시간 공백이 1초보다 길면 구간을 연결하지 않습니다.

`잠정 지표 = min(100, 100 × 구간 RMS 중앙값 / 2.8799 m/s²)`

분모는 기존 측정 데이터 RMS의 95백분위 값입니다. 0–100 연속 색상으로 표시하며 임의의 1–5등급 경계를 만들지 않았습니다. 다른 측정일의 데이터와 비교하려면 고정 기준·장착 조건·속도 영향을 별도로 검증해야 합니다.

## 해석 범위

이 값은 카메라 브리지에 부착된 휴대폰의 **상대 진동 대리 지표**입니다. 보행 충격, 장착부 움직임·공진, 시간 정합 오차, LiDAR 위치 오차가 포함됩니다. 높은 값이 노면 때문에 발생했다고 단정할 수 없으며, 0–100은 사고 확률이나 검증된 통행 위험등급이 아닙니다.

이 입력의 지도 Z는 평면화되어 있어 실제 경사·단차·기하학적 노면 거칠기를 산정하지 않았습니다. 움직이는 장애물이나 도로 폭도 이번 진동 지표에 포함되지 않습니다. 기존 Map_Demo의 시연 판정과 실측 지표를 섞지 않습니다.
